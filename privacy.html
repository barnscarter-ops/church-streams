Privacy policy

Church Streams. Last updated October 25, 2026.

Church Streams is used only by the media team of Full Life Assembly of God to create and update scheduled live broadcasts on the church's own YouTube channel.

What it accesses. With the signed-in team member's permission, it uses the YouTube Data API to create, read and update live broadcasts, their titles, descriptions and thumbnails on the church's channel. It does not access viewers' data.

What it stores. The sign-in token is stored only on the church's own computer, so the schedule can run each week. No data is sent to anyone else, sold, shared or used for advertising.

Removing access. Access can be revoked at any time at myaccount.google.com/permissions.

Church Streams' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
